# Zentrox.lk Portfolio

Premium React + Vite portfolio website for Zentrox.lk.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://127.0.0.1:5173/vite-index.html` for the React + Three.js version.

The main `index.html` is a direct-open standalone preview for quick viewing without installing packages.

## Build

```bash
npm run build
```

## Stack

- React + Vite
- Tailwind CSS
- React Three Fiber / Three.js
- Framer Motion
